\section{Related Work}\label{sec:related}

\paragraph{Zone representations.}
Minimal constraint systems were introduced by Larsen et
al.~\cite{LarsenLPY97} precisely to shrink the passed list, and are what UPPAAL
stores.  Testing inclusion against a minimal system without reconstructing the
dense matrix is implicit in that line of work; UDBM provides such operations, and
UPPAAL reports using ``minimal constraint systems with future testing''.  Our
contribution is not the test but the \emph{interaction} we document in
\cref{sec:diagnosis}: porting minimal-graph \emph{storage} while leaving the
\emph{query} path decompressing preserves the memory benefit and silently
introduces a large constant factor, which a parallel tool hides behind good
scaling.  We also give the composition with the coarser $\preceq_{aLU}$
abstraction as a two-tier test with an exactness proof
(\cref{thm:samestates}), which lets a tool keep the stronger abstraction and
still skip decompression in the common case.

\paragraph{Abstractions for termination.}
LU$^+$ extrapolation~\cite{Behrmann06} and the $\preceq_{aLU}$
preorder~\cite{Herbreteau12} are what make the zone graph finite and small.  Our
work is orthogonal: we change how a subsumption query is \emph{decided}, not
which abstraction is used, and \cref{thm:samestates} states exactly that.

\paragraph{Parallel explicit-state model checking.}
Parallel BFS with a shared hash table is well established~\cite{Stern01}, and
\textsc{DiVinE}~\cite{Barnat12} applies level-synchronous exploration in a
distributed setting.  The timed case differs in that ``already seen'' is
subsumption rather than equality, so the passed-list query is a geometric test
whose cost---not the hash table's contention---turned out to dominate here.

\paragraph{Parallel timed-automata verification.}
\textsc{LTSmin}~\cite{Kant15} parallelises timed exploration over a lock-free
table but stores states without subsumption, so it explores more symbolic states
than a subsumption-based tool.  Distributed reachability for timed
automata~\cite{Behrmann03} partitions the state space across nodes, where the
dominant concern is communication rather than per-query cost.  We retain
subsumption and, as \cref{sec:eval} reports, store exactly as many symbolic
states as sequential UPPAAL.

\paragraph{GPU-accelerated exploration.}
Level-synchronous frontier expansion is standard for GPU graph
traversal~\cite{Merrill12}.  Our GPU results are consistent with that
literature's central caveat---throughput depends on having enough work per
dispatch---and \cref{sec:eval} quantifies it for zone graphs: a $5.4\times$
difference in items per dispatch costs $2.9\times$ in per-item throughput.  We
additionally report that dispatch occupancy alone does not predict which backend
wins, because the merge and host path can dominate a well-occupied expansion.
